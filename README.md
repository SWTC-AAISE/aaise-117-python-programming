# 10-152-117 Python Programming Foundations

Student-facing course materials for Python programming foundations.

## Student workflow

1. Clone or fork the assigned starter repository to your personal GitHub account.
2. Develop locally, commit regularly, and push your work to your own repository.
3. Share the required repository link for evaluation. For paired work, use one shared repository and add both contributors.

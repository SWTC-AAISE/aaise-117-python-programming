# Week 8 Demo 6 - Run Instructions Example

## Files

* `main.py`
* `tasks.json`

---

## How to Run

```text
python main.py
```

---

## What the Program Does

* shows the current task list
* allows the user to add a task
* allows the user to mark a task complete
* saves changes to the JSON file

---

## Notes

* if `tasks.json` does not exist, the program creates it
* if the file is invalid, the program shows an error message

---

## Teaching Point

Even a small capstone benefits from clear run instructions.

If the instructor cannot run it easily, the project is harder to evaluate fairly.

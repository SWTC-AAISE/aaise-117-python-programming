# Course Task Tracker - Run Instructions

## Files

* `main.py`
* `tasks.json`
* `validation_checks.py`

---

## How to Run the App

Open a terminal in this folder and run:

```text
python main.py
```

The program starts with sample data from `tasks.json`.

---

## How to Run Validation Checks

```text
python validation_checks.py
```

The checks print actual values, expected values, and pass/fail results.

---

## What the Program Demonstrates

* menu-driven console interaction
* task input
* readable task output
* task completion tracking
* total planned minutes
* JSON save/load behavior
* simple validation evidence

---

## Evaluation Notes

The app intentionally avoids deadline, delete, and edit features. Those remain backlog items so the first completed version stays realistic and explainable.

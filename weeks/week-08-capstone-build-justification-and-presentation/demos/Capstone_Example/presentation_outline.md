# Course Task Tracker - Final Presentation Outline

## 1. What I Built

I built a Python console app that tracks assignment tasks for multiple courses.

---

## 2. Why I Chose It

Students often have small tasks spread across several classes. This project helps organize those tasks without making the program too large.

---

## 3. How It Works

The user can:

- view tasks
- add a task
- mark a task complete
- show a summary
- save task data

---

### 3.1. Demo User Interaction

The user interacts with the program through a console menu, selecting options to view, add, complete, and summarize tasks. Input is validated to ensure correct data entry, and feedback is provided for each action.

---

## 4. Course Concepts Used

- variables

- conditionals

- functions
- lists

---

## 5. How I Validated It

I checked:

- total planned minutes
- completed task count
- empty task lists
- missing task file behavior

---

## 6. How AI Was Used

AI helped review organization and possible validation checks. Final scope, testing, and explanation remained human decisions.

## 7. What I Would Improve Next

# Week 8 Demo 3 - AI Use Justification Example

## Project

Course Task Tracker

---

## Where AI Helped

AI helped by:

* suggesting alternate function names
* drafting an early version of the summary function
* listing possible edge cases for task completion logic

---

## What I Changed or Rejected

I changed:

* variable names that were too vague
* output messages so they matched my project better

I rejected:

* a class-based rewrite that made the project harder to explain
* extra features that would have pushed the scope too far

---

## What Decisions Remained Mine

I decided:

* the project purpose
* the feature scope
* the final structure
* what behavior needed testing
* what code to keep and what to revise

---

## Teaching Point

A strong AI justification does not merely say "I used AI."

It explains:

* where AI participated
* what the human governed
* what was accepted, changed, or rejected

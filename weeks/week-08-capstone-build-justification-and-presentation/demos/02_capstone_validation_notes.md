# Week 8 Demo 2 - Validation Notes Example

## Project

Study Task Tracker

---

## Important Behavior Checked

* completion rate calculation
* goal-status message logic
* zero-task edge case

---

## Why These Checks Matter

These checks verify behavior that a user would actually notice.

If these parts are wrong, the project may still run, but it would give misleading information.

---

## Teaching Point

Validation evidence does not need to be elaborate.

It does need to show that important behavior was tested intentionally.

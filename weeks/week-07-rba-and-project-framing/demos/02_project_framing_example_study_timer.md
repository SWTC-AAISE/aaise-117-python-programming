# Week 7 Demo 2 - Project Framing Example

## Project Name

Study Session Timer

---

## Purpose

Help a student track short study sessions and total minutes completed in one sitting.

---

## User

One student using a console-based Python program.

---

## Inputs

* session topic
* session minutes
* whether the session was completed

---

## Outputs

* list of entered sessions
* total completed minutes
* message showing whether the student reached a study goal

---

## Constraints

* must remain small enough for the course timeline
* should be explainable by a beginner
* should use concepts already covered
* should not depend on a large framework

---

## Likely Structure

* list of dictionaries to store session data
* functions for adding a session, showing sessions, and totaling minutes

---

## Risks or Unknowns

* input validation may become messy if scope grows
* file saving might be a later feature, not a first feature
* adding too many statistics could make the project too large

---

## AI-Use Boundaries

AI may help:

* suggest alternate function names
* draft a first version of a summary function
* compare organizational options

AI may not decide:

* the project purpose
* whether the project is too large
* what counts as a successful final build

# Week 7 Demo 1 - Prompt-First vs Intent-First

## Purpose

Show the difference between:

* asking AI for code before the project is framed
* defining intent and structure before AI participation

---

## Weak Start - Prompt First

> "Build me a Python study app."

### Likely problems

* scope is unclear
* audience is unclear
* features may be random
* structure may not match the real need
* success is hard to evaluate

---

## Stronger Start - Intent First

> "Build a small Python console app for a student to track study tasks for one week. It should allow adding tasks, marking tasks complete, and showing total planned minutes. Keep the structure beginner-readable with functions and lists of dictionaries. AI may help generate draft code, but the human decides the feature scope and validation rules."

### Why this is stronger

* purpose is clear
* user is clear
* scope is bounded
* structure is partly chosen
* evaluation criteria are easier to define

---

## Teaching Point

RBA does not start by asking AI for "something useful."

It starts by defining:

* what the project is for
* what boundaries matter
* what structure is likely appropriate
* where AI is helpful and where it is not the decision-maker

# Week 7 Demo 3 - Scope Reduction Example

## Starting Idea

> "I want to build a complete student productivity platform with reminders, login, schedules, analytics, AI recommendations, and mobile support."

---

## Why This Scope Is Weak for the Course

* too many features
* too many unknowns
* difficult to explain fully
* high risk of incomplete work
* likely to produce code the student cannot defend

---

## Reduced Version

> "I want to build a Python console app that lets a student enter study tasks, mark them complete, and see total planned vs completed minutes."

---

## Why This Scope Is Better

* still useful
* fits course concepts
* supports explanation and testing
* realistic within the timeline
* easier to revise if problems appear

---

## Teaching Point

Scope reduction is not failure.

Scope reduction is often what makes a project finishable, testable, and explainable.

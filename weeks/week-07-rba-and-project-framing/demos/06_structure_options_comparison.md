# Week 7 Demo 6 - Structure Options Comparison

## Project Idea

Study Task Tracker

---

## Option 1 - Single Script

### Strengths

* fast to start
* simple for very small projects

### Risks

* logic can become crowded
* harder to revise cleanly as features grow

---

## Option 2 - Function-Based

### Strengths

* responsibilities can be named clearly
* easier to test and explain
* fits the course well

### Risks

* still needs discipline to avoid messy shared state

---

## Option 3 - Simple Class-Based

### Strengths

* groups related data and actions together
* useful when AI returns class-based organization

### Risks

* can add extra vocabulary for beginners
* may be unnecessary for a very small tool

---

## Teaching Point

RBA framing includes choosing a likely structure before major generation begins.

That decision does not have to be perfect.

It does need to be intentional.
